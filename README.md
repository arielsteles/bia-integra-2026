# Bacharelado em Inteligência Artificial — UFDPar

Landing page estática e responsiva, sem necessidade de build ou instalação de dependências.

## Visualizar localmente
Abra `index.html` no navegador ou execute `python3 -m http.server 8000` nesta pasta.

## Publicar na Vercel
1. Envie esta pasta para um repositório GitHub.
2. Na Vercel, selecione **Add New → Project** e importe o repositório.
3. Em **Framework Preset**, selecione **Other**; não é necessário comando de build.
4. Publique e copie a URL final para gerar o QR Code.

## Antes da publicação
- Confirmar o texto e a oferta de vagas com a coordenação e os editais vigentes.
- Substituir a marca tipográfica por um logotipo oficial, se desejado.
- Adicionar link para o PPC público quando houver URL oficial.
- O banner original está em `assets/banner.jpg` como referência de identidade visual e não é exibido na página.

Conteúdo-base: PPC do Bacharelado em IA da UFDPar (2025), especialmente páginas 7–13.


## Logo da UFDPar
Coloque a imagem oficial em `assets/logo-ufdpar.png` (PNG com fundo transparente recomendado).
A dimensão da logo é controlada automaticamente pelo CSS (54 × 54 px, com `object-fit: contain`); não é necessário redimensionar o arquivo original.
Enquanto o arquivo não for adicionado, aparece um espaço reservado escrito LOGO.
